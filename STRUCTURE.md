# Структура интеграции Almatel

```
almatel_integration/
│
├── 📄 README.md                    # Подробная документация
├── 📄 INSTALL.txt                  # Быстрая установка
├── 📄 INSTALL.md                   # Установка в Markdown
│
├── 📁 custom_components/
│   └── 📁 almatel/                 # ← СКОПИРУЙТЕ ЭТУ ПАПКУ В HA
│       ├── __init__.py             # Главный файл интеграции
│       ├── config_flow.py          # UI для настройки
│       ├── sensor.py               # Создание сенсоров
│       ├── const.py                # Константы
│       ├── manifest.json           # Описание интеграции
│       ├── services.yaml           # Описание сервисов
│       ├── strings.json            # Тексты интерфейса
│       └── translations/
│           └── ru.json             # Русский перевод
│
└── 📁 appdaemon/
    └── 📁 apps/                    # ← СКОПИРУЙТЕ ФАЙЛЫ В APPDAEMON
        ├── almatel.py              # Скрипт для работы с Selenium
        └── apps.yaml.example       # Пример конфигурации
```

## 🎯 Что делает каждый файл

### Custom Components (Интеграция HA)

**__init__.py**
- Регистрирует интеграцию в HA
- Создаёт сервис `almatel.update_balance`
- Сохраняет конфигурацию для AppDaemon
- Отправляет MQTT команды

**config_flow.py**
- Создаёт красивую форму настройки через UI
- Валидирует введённые данные
- Поддерживает изменение настроек

**sensor.py**
- Создаёт 3 сенсора:
  * sensor.almatel_balance (баланс)
  * sensor.almatel_due_date (дата оплаты)
  * sensor.almatel_days_left (дней до оплаты)
- Подписывается на MQTT топики
- Обновляет значения автоматически

**const.py**
- Хранит все константы (топики, ключи конфигурации)
- Облегчает изменение параметров

**manifest.json**
- Описывает интеграцию для HA
- Указывает зависимости (paho-mqtt)

**services.yaml**
- Определяет сервис обновления баланса
- Описание для UI

**strings.json + translations/ru.json**
- Русские тексты для интерфейса
- Названия полей, ошибок, описания

### AppDaemon

**almatel.py**
- Использует Selenium для авторизации на Almatel
- Извлекает баланс и дату оплаты
- Публикует данные в MQTT
- Слушает команды на обновление

**apps.yaml.example**
- Пример конфигурации AppDaemon
- Скопируйте в apps.yaml и отредактируйте

## 🔧 Интервалы обновления

- **Автоматическое обновление**: каждые 3600 секунд (1 час) 
  настраивается через Config Flow
  
- **Ручное обновление**: 
  - Сервис: `almatel.update_balance`
  - MQTT: команда "update" в топик `custom_sensors/almatel/command`

## 🚀 Порядок запуска

1. Home Assistant загружает интеграцию
2. Интеграция создаёт сенсоры (пока без данных)
3. AppDaemon запускает almatel.py
4. almatel.py подключается к Almatel через Selenium
5. Данные публикуются в MQTT
6. Сенсоры получают данные из MQTT
7. Данные отображаются в UI

## 💾 Где хранятся настройки

- **HA конфигурация**: `.storage/core.config_entries`
- **AppDaemon конфиг**: `appdaemon/apps/apps.yaml`
- **Общий конфиг**: `/config/almatel_config.json` (создаётся автоматически)

## 🔐 Безопасность

- Пароли в HA хранятся зашифровано
- AppDaemon читает пароли из конфига
- MQTT использует аутентификацию
- Selenium работает в headless режиме

## 📝 Логирование

- **HA логи**: Настройки → Система → Журналы (фильтр: almatel)
- **AppDaemon логи**: `/config/appdaemon/logs/almatel_checker.log`
- **MQTT логи**: логи вашего MQTT брокера

## ✅ Проверка работоспособности

После установки проверьте:

1. ✓ Интеграция добавлена в HA
2. ✓ Созданы 3 сенсора
3. ✓ AppDaemon запущен
4. ✓ MQTT брокер работает
5. ✓ Selenium может подключиться к Almatel
6. ✓ Данные обновляются

## 🐛 Типичные проблемы

**Сенсоры created но unavailable:**
→ AppDaemon ещё не отправил данные, подождите или запустите обновление вручную

**Ошибка авторизации:**
→ Проверьте логин/пароль Almatel

**MQTT ошибки:**
→ Проверьте, запущен ли брокер и правильность учётных данных

**Selenium ошибки:**
→ Проверьте наличие ChromeDriver в AppDaemon контейнере
